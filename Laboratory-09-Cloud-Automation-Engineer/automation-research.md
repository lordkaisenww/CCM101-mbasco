# Checkpoint 2 - Research: The Language of Automation

## 1. Bash Script
A Bash script is a file that contains Linux commands that run automatically in order. The #!/bin/bash line is called a shebang, and it tells the system to use Bash to execute the script.

## 2. Variables
Variables are used to store values like folder paths, filenames, or numbers so we don't need to type them again and again. For example, $BACKUP_DIR makes our script easier to update because we only need to change the folder path in one place.

## 3. Cron Job
A cron job is a Linux feature that runs commands or scripts automatically at a scheduled time. It is important in cloud operations because it helps automate tasks like backups, system maintenance, and log cleanup without doing them manually.
