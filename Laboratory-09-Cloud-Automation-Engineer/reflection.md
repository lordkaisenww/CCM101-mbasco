# Mission 9 Reflection

Automation is very important in cloud computing because managing hundreds of servers manually takes too much time and effort. If a cloud engineer needs to back up files or update systems on many servers, doing everything one by one is difficult. With automation, we can create scripts that perform tasks automatically, which saves time and makes our work easier.

However, automation also has some risks. If there is a wrong command or destructive typo inside a script, it can cause serious problems. For example, if a script accidentally deletes important files and runs on 1,000 servers, all those servers could lose their data. That is why testing and checking scripts before using them is very important.

Writing a Bash script is different from creating a Docker Compose YAML file in Mission 6. In Bash scripting, I wrote Linux commands that execute step by step to perform tasks like creating backups. In Docker Compose, I used YAML to define and configure multiple containers. Bash focuses on executing commands, while Docker Compose focuses on managing container services.

Looking back from Laboratory 1 to Laboratory 9, I learned many things about cloud computing. Before, I thought cloud computing was only about storing files online. But after completing the laboratories, I learned about cloud infrastructure, virtualization, Docker, cloud storage, databases, security, and automation. I also learned how to use Linux commands and GitHub to manage and document my activities. These laboratories helped me understand how cloud systems work in real situations.

The role I enjoyed the most was Cloud-Native Engineer because I liked working with Docker and deploying applications using containers. It was interesting to see how applications can run inside containers without installing everything manually. Overall, this semester helped me improve my technical skills and gave me more confidence in learning cloud computing.
