# Laboratory 02: Build the Cloud Infrastructure Blueprint

Mission Overview

This laboratory focused on planning cloud infrastructure using the KillerCoda Playground. I investigated a Linux server, identified cloud infrastructure components, compared AWS, Azure, and GCP services, and created a basic cloud architecture diagram.

Objectives

- Understand major cloud infrastructure components
- Investigate Linux server resources
- Differentiate compute, storage, networking, and identity
- Create technical documentation
- Improve my GitHub cloud computing portfolio

Cloud Infrastructure Components

- Compute — runs applications using CPU and RAM
- Storage — stores data and files
- Networking — connects systems and the internet
- Operating System — manages hardware and software resources
