# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 / EBS | Azure Blob Storage / Managed Disks | Cloud Storage / Persistent Disk |
| Networking | Amazon VPC | Azure Virtual Network (VNet) | Google Cloud VPC |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Google Cloud IAM |

## Guide Questions

1. Which cloud provider offers the broadest range of services? Explain your answer.

AWS is widely considered to offer the broadest range of services, since it was the first major public cloud provider and has continuously expanded its catalog to cover hundreds of services across compute, storage, networking, AI, IoT, and more. Its long head start gave it the largest ecosystem and the most mature set of tools.

2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

Microsoft Azure would be the best fit for such an organization, because it integrates natively with Microsoft products like Windows Server, Active Directory, Office 365, and .NET. This tight integration reduces friction for teams already invested in the Microsoft ecosystem.

3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized in this area, since Kubernetes was originally developed by Google and GCP offers strong native support for it. GCP also provides advanced AI/ML tools such as Vertex AI, backed by Google's research in machine learning.

4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent core infrastructure categories — compute, storage, networking, and identity and access management — just under different product names. They also share common characteristics such as pay-as-you-go pricing, global data center availability, and strong security and compliance offerings.
