# Mission Reflection
This laboratory activity helped me understand the importance of cloud infrastructure and how its different components work together. Among the components covered, I consider compute to be the most important because it runs applications and processes, while storage keeps data and networking allows information to move between systems. The KillerCoda VM gave me hands-on experience with a compute resource and helped me understand its CPU, RAM, operating system, and overall capabilities. I also learned how Linux supports cloud computing because it is open-source, stable, lightweight, and highly customizable, making it suitable for virtual machines, containers, and large-scale cloud environments. Using the KillerCoda Playground allowed me to experience how a Linux-based cloud server works in practice.
I also realized that technical documentation is an important part of planning and deploying infrastructure because it records the resources, configurations, decisions, and relationships between components. Proper documentation helps teams work together, reduces errors, makes troubleshooting easier, and allows infrastructure decisions to be understood and repeated. During this activity, I developed new technical skills by using Linux commands such as lscpu, free -h, df -h, and mount to investigate server specifications. I also improved my skills in writing Markdown documentation, organizing files in GitHub, comparing cloud services from AWS, Azure, and GCP, and using Git commands to commit and push changes to a remote repository.
Overall, this laboratory activity improved my GitHub portfolio by adding a well-organized second laboratory folder containing documentation, a server investigation report, a cloud component breakdown, a cloud provider comparison, and a visual infrastructure diagram. Instead of having scattered files, my repository is becoming more structured and professional. This experience helped me better understand the fundamentals of cloud infrastructure while also developing practical Linux, Git, GitHub, documentation, and cloud computing skills that can be useful in my future career in IT and cloud infrastructure.
