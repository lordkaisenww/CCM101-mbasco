# Security Audit Report

## The Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the access they need to do their work. This is important because it can prevent unauthorized access and protect important files from being deleted or change. By using this principle, we can make our system more safe and secure.

## Attack Surface

Attack Surface is the possible ways where hackers can enter or attack our system, like open ports, websites, and applications. If our system have many open ports and unused services, hackers can have more chances to attack it. We can reduce this by closing unused ports, updating our system, and using strong passwords.

## Default Deny Policy

Default Deny Policy means all connections and access are automatically blocked unless the administrator allow it. This is important because it helps prevent unknown users and untrusted connections from entering our system. By applying this policy, we can control who can access our system and protect our data from possible attacks.
