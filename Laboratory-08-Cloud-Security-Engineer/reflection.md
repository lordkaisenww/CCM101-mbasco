# Mission 8 Reflection

In this laboratory, I learned how important a host-based firewall is for protecting our server from possible security threats. A host-based firewall protects the server by controlling the incoming and outgoing network traffic. Even if hackers manage to enter the physical network, the firewall can still block connections that are not allowed. This is important because the firewall works directly on the server and provides another layer of security. By using UFW, we can control which ports and services are allowed to communicate with our system.

I also learned that managing open network ports is important because hackers can use them to find weaknesses in our server. Every open port can be a possible entry point for attackers, especially if the service running on that port is not properly secured. If we leave unnecessary ports open, our server may become more vulnerable to attacks. That is why we need to close unused ports and only allow the ports that are needed, like SSH and port 8080 for our web application. This helps reduce the attack surface and makes our server more secure.

In a real enterprise environment, leaving a database port like 3306 for MySQL open to the public internet is very dangerous. Hackers might try to access the database by guessing passwords or taking advantage of security vulnerabilities. If they successfully enter the database, they could steal, modify, or delete important information, including customer and company records. This can cause serious problems for the company, such as data loss and security breaches. To prevent this, database ports should only be accessible to trusted applications and authorized users through private networks.

Overall, this laboratory helped me understand how firewall rules can protect a cloud server. I learned that even simple commands can make a big difference in improving security. As a future IT professional, I can apply this knowledge when managing servers and cloud infrastructure.
