# Laboratory Activity 1 - Mission 1: Welcome to the Cloud

## Mission Overview
Completed the Cloud Engineer Onboarding Challenge as a Junior Cloud Infrastructure Engineer Trainee, covering Linux basics, system administration, and GitHub portfolio setup.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
1. Launched an Ubuntu 24.04 Playground on KillerCoda
2. Created a new user with sudo privileges and logged in
3. Investigated the Linux environment (distro, kernel, CPU, memory, disk)
4. Built a folder structure (Documents, Notes, Reports, Screenshots)
5. Created and documented markdown files
6. Set up a GitHub repository as a Cloud Computing Portfolio

## Linux Commands Used
- sudo adduser - Create a new user
- usermod -aG sudo - Grant sudo privileges
- whoami, pwd, hostname - Check user/session info
- lsb_release -a - Check Linux distribution
- uname -r - Check kernel version
- lscpu - Check CPU info
- free -h - Check memory usage
- df -h - Check disk space
- mkdir, cat, ls - File/directory management
- git clone/add/commit/push - Version control

## Skills Learned
- Basic Linux navigation and system administration
- Creating and managing users and permissions
- Writing technical documentation in Markdown
- Using Git and GitHub for version-controlled portfolios
