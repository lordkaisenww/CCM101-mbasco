My Cloud Computing Mission Reflection

The cloud platform that impressed me the most is Amazon Web Services or AWS. When I doing this laboratory, I learned that AWS have many services like EC2 for virtual machine, S3 for storage, RDS for database, and Lambda for serverless. I choose AWS because it have many services that can be use for different business needs.

AWS, Azure, and Google Cloud have many similarities. All of them provide cloud computing, storage, database, networking, security, and virtual machines. They also support Linux and Windows, containers, automation, and application development. Even their services have different names, they can still do almost the same purpose.

Business requirements is very important in choosing a cloud platform. We need to consider the budget, type of application, security, performance, existing technology, and future growth of the company. For example, if the company already using Microsoft products, Azure can be a good choice. For AI and Kubernetes, Google Cloud can also be a good option.

When I act as a Cloud Solutions Consultant, I learned how to understand the needs of different clients and recommend the cloud platform for them. I learned that we cannot just choose a cloud platform because it is popular. We need to check first what the business really needs.

My GitHub Cloud Computing Portfolio improved because I added my research about AWS, Azure, and GCP. I also created comparison tables, client recommendations, Linux investigation, and this reflection. I also learned more about using Linux commands, Git, GitHub, and organizing my files. This laboratory help me understand cloud computing more and improve my skills as a student.
